# Full selective language evolution v1

This protocol is fixed before evaluating the four paired meta-seeds 211, 223, 227 and 229. It compares three screening selectors: full population, compression proxy and the frozen semantic value model. The method order rotates by seed. Each selector independently starts with an empty library and the same 160 training functions, neural policy, task splits and inner random seeds.

All arms use three generations, 256 candidate languages, fresh development stages of 8+16, 8+16 and 12+36 tasks, and identical inner evaluation/work caps. Four screen winners plus base/current parents enter medium evaluation; two parents survive. Full selection measures every candidate; selective arms rank first and measure the top sixteen plus base/current parents. Every ranking and shortlist is written before candidate synthesis. The neural policy and value model never update. Subsequent corpora/languages can diverge as a consequence of selection.

Final language freezes before 80 confirmation functions and 200 final functions, with three optimizer seeds and the same four base/library × uniform/prior arms. The pre-existing two-standard-error confirmation rule is unchanged. Rejected candidate results remain visible; accepted-library comparisons fall back to base. Nested/longer families remain absent from language selection. Selection and final functions exclude known prior programs/subtrees, historical pilot/calibration functions, source-value-dataset tasks, previous prospective tasks and each run's training functions using the recorded empirical signature rule.

The primary comparison is final search utility against **complete incremental discovery cost**, not screening query counts alone. Report all paired outcomes and structural groups. Four seeds are a pilot, not a substitute for the 20-run replication. The frozen value model's conservative 455.4M-work source-discovery investment, its training cost and shared neural pretraining remain separate additional investments; no global amortization is claimed. Previously trained model costs cannot be erased by quoting only the online shortlist cost.

This experiment actually runs every arm, so total research expense includes them all. Independent candidate-query, complete-program, structural-work, point-check and wall counters remain distinct. Wall timings are observational on a shared host. No same-quality threshold or noninferiority margin is invented after seeing results. A report may describe gains, regressions, intervals and cost ratios without declaring equivalence.

Run `npx tsx scripts/selective-evolution.ts`. Source and model hashes are sealed in `output/joint/selective-evolution-v1/protocol.json` before the first run. Completed artifacts can be resumed under exactly the same protocol. In-flight progress is not a restart checkpoint; interrupted work must be audited and charged before a rerun.
